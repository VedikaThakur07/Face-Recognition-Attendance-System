# Face Recognition Based Attendance System

## Overview

The Face Recognition Based Attendance System is a Python-based application that automates attendance management using facial recognition technology. The system captures facial images through a webcam, recognizes registered students, and automatically records attendance with date and time.

## Features

* Automatic Attendance Marking
* Face Detection and Recognition
* User-Friendly GUI
* Fast and Accurate Identification
* Digital Attendance Record Storage
* Reduced Manual Effort
* Prevention of Proxy Attendance

## Technologies Used

* Python
* OpenCV
* Tkinter
* NumPy
* PIL (Python Imaging Library)
* CSV Storage

## System Workflow

1. Register Student Details
2. Capture Face Images
3. Store Images in Dataset
4. Train the Recognition Model
5. Detect and Recognize Faces
6. Mark Attendance Automatically

## Project Structure

* Dataset Folder
* Training Module
* Face Recognition Module
* Attendance Records
* GUI Interface

## Advantages

* Saves Time and Effort
* Reduces Human Errors
* Secure and Reliable Identification
* Easy Attendance Management
* Paperless Record Keeping
